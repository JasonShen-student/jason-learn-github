# GitHub Basics 学习笔记

日期：2026-10-10

## 我学到的内容

- Git 是版本控制工具，GitHub 是托管 Git 仓库和开展协作的平台。
- Repository 是一个项目及其历史记录的家。
- Commit 是一次带有说明的版本快照。
- Branch 可以隔离尚未完成的修改。
- Pull Request 用来检查、讨论并合并分支上的修改。
- Merge 会把一个分支的成果纳入另一个分支。

## 我的实践记录

1. 创建了自己的仓库。
2. 编辑了 README。
3. 创建了新分支。
4. 在分支上提交了修改。
5. 创建并合并了 Pull Request。
